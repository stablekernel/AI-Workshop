# Half-Day Workshop (4 hours)

**Audience**: Teams new to structured LLM usage or seeking to level up from ad-hoc prompting.

**Prep**: Review [SHRINE patterns overview](https://stablekernel.github.io/SHRINE/patterns/overview/) before delivering.

## Agenda

### Block 1: Mental Models (60 min)

| Time | Topic | SHRINE Link |
|------|-------|-------------|
| 0:00 | Welcome, objectives, what we will NOT cover | |
| 0:10 | The context window: what it is, why it matters | |
| 0:25 | [TTV (Tokens to Value)](https://github.com/stablekernel/SHRINE/discussions/2): the north star | Proposal #2 |
| 0:40 | Live demo: same task, different context loading, different results | |
| 0:55 | Q&A | |

### Break (15 min)

### Block 2: Core Patterns (75 min)

| Time | Topic | SHRINE Link |
|------|-------|-------------|
| 1:15 | [Structured Output](https://stablekernel.github.io/SHRINE/patterns/structured-output/): schemas beat prose | Pattern |
| 1:30 | [Mechanical Scaffolding](https://stablekernel.github.io/SHRINE/patterns/mechanical-scaffolding/): build once, fill with context | Pattern |
| 1:50 | Live demo: Jira ticket generator (scaffold vs. from-scratch) | |
| 2:10 | Verification: [Adversarial Review](https://stablekernel.github.io/SHRINE/patterns/adversarial-review/), [Self-Critique](https://stablekernel.github.io/SHRINE/patterns/self-critique/) | Patterns |
| 2:30 | Q&A | |

### Break (15 min)

### Block 3: Hands-On Exercise (60 min)

| Time | Topic |
|------|-------|
| 2:45 | Exercise intro: build a scaffold for YOUR repetitive task |
| 2:55 | Pair work: identify task, design scaffold, define inputs |
| 3:25 | Build and test with live model |
| 3:45 | Share-outs: what worked, what surprised you |

### Block 4: Wrap-Up (15 min)

| Time | Topic |
|------|-------|
| 4:00 | Key takeaways: TTV, scaffolding, verification |
| 4:05 | Resources: [SHRINE docs](https://stablekernel.github.io/SHRINE/), patterns to explore next |
| 4:10 | Open discussion |

## Materials Needed

- Access to Claude Code, Cursor, or equivalent [harness](https://stablekernel.github.io/SHRINE/stack/harness/)
- Sample domain data from attendee's actual work
- SHRINE patterns overview (printed or on second screen)

## Outcomes

Attendees leave with:
- Understanding of TTV as the measure that matters
- One working scaffold for a real task
- Vocabulary to discuss LLM usage with their team
