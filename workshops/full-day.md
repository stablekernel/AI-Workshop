# Full-Day Workshop (8 hours)

**Audience**: Teams building AI-assisted workflows or integrating LLMs into products.

## Agenda

### Morning Session

#### Block 1: Foundations (90 min)

| Time | Topic |
|------|-------|
| 0:00 | Welcome, objectives, participant intros |
| 0:15 | The context window: mechanics and mental model |
| 0:35 | TTV deep dive: measuring what matters |
| 0:55 | Model selection: when to use what |
| 1:15 | Live demo: task routing across models |
| 1:30 | Q&A |

#### Break (15 min)

#### Block 2: Prompting Patterns (75 min)

| Time | Topic |
|------|-------|
| 1:45 | Chain of thought: forcing explicit reasoning |
| 2:00 | Few-shot examples: teaching by showing |
| 2:15 | Structured output: schemas, JSON mode, tool use |
| 2:35 | Lab: convert a prose prompt to structured |
| 3:00 | Q&A |

#### Lunch (60 min)

### Afternoon Session

#### Block 3: Mechanical Scaffolding (90 min)

| Time | Topic |
|------|-------|
| 4:00 | The pattern: separate structure from content |
| 4:15 | Case study: Jira tickets, PR bodies, status reports |
| 4:35 | Building a scaffold: inputs, template, validation |
| 4:55 | Lab: design a scaffold for your team's workflow |
| 5:30 | Share-outs |

#### Break (15 min)

#### Block 4: Verification and Trust (60 min)

| Time | Topic |
|------|-------|
| 5:45 | Why verification matters: failure modes |
| 6:00 | Self-critique: having the model check itself |
| 6:15 | Adversarial review: external skeptic pattern |
| 6:30 | Multi-model consensus: independent validation |
| 6:45 | Q&A |

#### Break (15 min)

#### Block 5: Orchestration (60 min)

| Time | Topic |
|------|-------|
| 7:00 | When single prompts are not enough |
| 7:10 | Pipeline orchestration: chaining stages |
| 7:25 | Subagent fanout: parallel work distribution |
| 7:40 | Live demo: code review workflow |
| 8:00 | Q&A |

#### Block 6: Synthesis and Next Steps (30 min)

| Time | Topic |
|------|-------|
| 8:00 | Recap: patterns covered |
| 8:10 | Action planning: what will you try Monday? |
| 8:20 | Resources and continued learning |
| 8:30 | Close |

## Materials Needed

- Laptops with Claude Code, Cursor, or similar
- Real domain data from attendees
- SHRINE docs (full site access)
- Whiteboard for diagramming

## Outcomes

Attendees leave with:
- Deep understanding of context economics and model selection
- Multiple working scaffolds for real tasks
- Verification strategy for their use case
- Action plan for team adoption
